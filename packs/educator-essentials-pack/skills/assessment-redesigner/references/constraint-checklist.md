# Constraint Checklist — So the Redesign Survives Reality

A redesign the instructor can't actually run is not a redesign. Before finalizing,
walk these constraints and adjust the direction to fit. Surface any that clash so
the instructor decides the trade-off — don't quietly hand back something unworkable.

## Class size

- [ ] **How many students, and is there grading or facilitation help?** Live oral
      formats (AI-Resistant Design) scale badly alone. For large sections: group
      formats, staged presentations across weeks, structured peer assessment, or
      randomized/spot oral checks rather than universal ones.
- [ ] Does the redesign multiply grading load per student? If so, is there a rubric
      and a way to keep feedback efficient? (Pair with the Rubric Builder and the
      Feedback First-Pass skills.)

## Modality

- [ ] **Synchronous, asynchronous, or hybrid?** Real-time formats assume contact
      time. A fully-async course needs asynchronous equivalents: recorded
      process-documentation video, discussion-based defenses, timed in-platform
      work.
- [ ] **In-person, online, or both?** Some AI-Resistant forms (live improvisation,
      field-site work) assume physical presence. Name the online-equivalent up front.

## Grading capacity

- [ ] **What's the realistic per-student grading budget?** Documentation logs,
      reflections, and contribution trails are powerful but add reading. Right-size:
      assess a focused slice well rather than everything shallowly.
- [ ] **Is the rubric ready?** A redesign that changes what's measured needs a rubric
      that measures the new thing (process, judgment, intervention) rather than the
      old artifact.

## Accessibility and equity

- [ ] **Do live/oral formats have equitable alternatives?** Timed, in-body, or
      on-the-spot formats can disadvantage students with anxiety, disabilities, or
      caregiving constraints. Build the alternative in from the start, not as an
      exception.
- [ ] **Does it assume tools, devices, or paid AI access every student has?**
      Exploratory and AI-Augmented categories assume access. Specify a free-tier path
      or provide institutional access.
- [ ] **Does it protect student privacy?** If student work or data goes into an AI
      tool, note the anonymization and account guidance.

## Durability

- [ ] **Will it survive the next model release?** "Hard for AI today" ages fast.
      Favor redesigns that measure something durable (live judgment, documented
      process, discipline-specific reasoning) over ones betting on a current
      limitation.
- [ ] **Can the instructor explain it in two sentences?** A redesign nobody
      understands gets reverted. The rationale has to travel to colleagues, students,
      and next term's version of the course.

## The trade-off rule

If the best pedagogical redesign collides with a hard constraint, say so plainly and
offer the strongest version that fits — plus what the instructor gives up by fitting
it. An honest "the ideal is a live defense, but for 200 students the workable version
is staged group presentations with spot checks; here's what that trades away" beats a
perfect plan they'll never run.
