# Rubric-Quality Checklist

Run every drafted rubric through this before showing it to the instructor. It's the
quality gate that separates a usable rubric from a plausible-looking one. Fix issues
silently in the draft; flag only the trade-offs that need the instructor's call.

## Criteria

- [ ] **Observable, not inferred.** Each criterion points to evidence a rater can
      see. Rewrite "demonstrates understanding" into what understanding looks like
      here ("applies the concept correctly to a new case").
- [ ] **One idea per row.** No double-barreled criteria. "Clear and well-organized"
      becomes two rows, because a paper can be clear but disorganized.
- [ ] **Aligned to the assessment's real goal.** Every criterion measures something
      the task is actually for. Cut rows that grade compliance or effort unless those
      are genuinely the goal.
- [ ] **Independent.** Criteria don't overlap so much that one weakness is punished
      three times.

## Levels

- [ ] **Levels genuinely differ.** Adjacent descriptors are distinguishable by more
      than an adverb. "Excellent analysis / good analysis / fair analysis" is not a
      rubric — say what changes between levels.
- [ ] **Described by evidence, not just quality words.** Each level names what the
      work does, not only how good it is.
- [ ] **Consistent direction.** Every criterion's levels run the same way (high to
      low) so raters don't whiplash.

## Weighting

- [ ] **Weights match stated values.** If "argument" is the point of the course but
      "mechanics" carries 40%, surface the mismatch.
- [ ] **Transparent to students.** Weights are visible, not hidden in the grade book.
- [ ] **No false precision.** Don't split hairs the rater can't actually judge; a
      4-level scale reliably graded beats a 7-level one that isn't.

## Usability

- [ ] **A student can self-assess against it.** If a student can't predict their
      score by reading it, feedback won't land either.
- [ ] **A second rater would mostly agree.** The descriptors are concrete enough for
      inter-rater reliability.
- [ ] **Sized to the stakes.** A low-stakes task doesn't need a fifteen-row grid; a
      capstone shouldn't get a 4-point holistic scale.

## Fairness

- [ ] **No proxies for background or resources.** Criteria measure the learning, not
      polish that tracks prior advantage.
- [ ] **Accessible language in the student version.** Jargon translated; expectations
      legible to the whole class.

## The two-question gut check

1. **Would two raters land close?** If not, the descriptors are too vague.
2. **Does the highest weight sit on the thing the assignment is really for?** If not,
   the rubric will train students toward the wrong target.
