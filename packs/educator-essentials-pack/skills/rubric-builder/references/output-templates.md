# Output Templates

Every rubric ships in two forms: an instructor version (complete, weighted, for
grading) and a student-facing version (same criteria, plain language, for
understanding the target). Produce both. In a file-capable tool, deliver them as a
formatted document; in plain chat, format cleanly in the reply and offer a
copy-pasteable version.

---

## Instructor version (analytic template)

```
# Rubric — <Assignment name>
Total: <points> · Type: Analytic

| Criterion (weight) | Exemplary (<pts>) | Proficient (<pts>) | Developing (<pts>) | Beginning (<pts>) |
|---|---|---|---|---|
| <criterion 1> (<%>) | <evidence> | <evidence> | <evidence> | <evidence> |
| <criterion 2> (<%>) | … | … | … | … |

Scoring notes: <how to combine, rounding, any non-negotiables>
```

---

## Student-facing version

Same criteria, translated. Drop internal point mechanics; keep what earns a strong
grade in language a student reads before starting.

```
# What this assignment is looking for — <Assignment name>

**<Criterion 1, plain name>.** A strong submission: <what proficient/exemplary looks
like, in the student's terms>. Common misstep: <what weak work does>.

**<Criterion 2, plain name>.** …

**How it's weighted.** <plain statement of what matters most and why.>
```

---

## Holistic template (instructor)

```
# Rubric — <Assignment name>
Total: <points> · Type: Holistic

**<top> — <label>.** <integrated description of work at this level>
**<next> — <label>.** …
```

## Single-point template (instructor)

```
# Rubric — <Assignment name> · Type: Single-point

| Below target (notes) | Proficient — the target | Above target (notes) |
|---|---|---|
|  | <criterion 1: what proficient looks like> |  |
|  | <criterion 2> |  |
```

---

## Delivery notes

- **Formatted document when possible.** The instructor should be able to drop it
  straight into an LMS or a handout without reformatting.
- **Lead with the student version's usefulness.** Remind the instructor that
  publishing the student-facing version up front is one of the cheapest ways to raise
  submission quality.
- **Hand off to feedback.** Note that the finished rubric plugs directly into the
  Feedback First-Pass skill, which drafts comments tied to these exact criteria.
