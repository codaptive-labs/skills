# Educator Essentials Pack

Eight installs is seven too many. This is the teaching wave in one bundle — the
assessment suite, the feedback and letters pair, and the responsible-AI pair —
installed together, sharing vocabulary, updating together.

## What's inside

Eight coordinated skills:

| Skill | What it does |
|---|---|
| **Assessment Redesigner** | Rebuilds an assignment so the thinking is visible again, via the five-category framework. |
| **Assessment AI Policy Writer** | Sets AI expectations one assessment at a time; rolls up into a syllabus section. |
| **Rubric Builder** | Turns rubric-writing into a short interview with a quality gate; formatted output. |
| **Confusion Forecaster** | Predicts where students will get lost before they do, with smallest-edit fixes. |
| **Feedback First-Pass** | Drafts formative feedback in your voice, against your rubric. Never grades. |
| **Letter of Rec Drafter** | Turns your notes into a voice-true recommendation letter, shaped to the opportunity. |
| **Source Auditor** | Verifies citations and claims; returns a confirmed / unverifiable / contradicted table. |
| **AI Use Disclosure** | Drafts an honest, right-sized disclosure of how AI was used, matched to the venue. |

## How the pieces coordinate

They share the same frameworks and terms, so workflows hand off cleanly: the
Assessment Redesigner's vocabulary feeds the Rubric Builder feeds the AI Policy
Writer; the finished rubric feeds Feedback First-Pass; the AI Policy Writer's
disclosure norms pair with the AI Use Disclosure skill.

## Installing

- **Claude Code:** `/plugin marketplace add codaptive-labs/skills`, then
  `/plugin install educator-essentials-pack@codaptive-skills`.
- **Cowork:** download the pack, then add the plugin bundle under Customize → Plugins.
- **Claude.ai:** plain chat can't install bundles, but every skill inside is also
  listed individually on [codaptivelabs.com/skills](https://codaptivelabs.com/skills) —
  grab the ones you want as single `.zip`s.

Every member skill is also available on its own. The pack is convenience, not
lock-in.
